# OLA Ride Data Analysis 🚖

## 📌 Project Overview
This project analyzes OLA ride booking data using SQL and Power BI to generate business insights on ride performance, cancellations, revenue, and customer behavior.

## 🎯 Objectives
- Analyze ride trends and booking patterns
- Identify cancellation reasons
- Evaluate customer and driver ratings
- Measure revenue and payment trends

## 🛠 Tools Used
- SQL (PostgreSQL)
- Power BI
- Excel / CSV

## 📊 Key Insights
- Peak ride demand observed on specific dates/times
- High cancellation rates impacting revenue
- UPI is the most preferred payment method
- Certain vehicle types generate higher ride distance

## 📈 Dashboard Features
- Ride Volume Over Time
- Booking Status Analysis
- Revenue by Payment Method
- Customer vs Driver Ratings

## 💡 Recommendations
- Reduce cancellations through penalties
- Improve driver incentives
- Optimize peak-hour pricing
- Enhance customer experience

## 📂 Files Included
- Dataset (CSV)
- SQL Queries
- Power BI Dashboard
